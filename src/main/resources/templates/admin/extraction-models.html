추출 모델

추출에 쓰는 LLM 모델을 경로별로 지정합니다.

동작 방식
저장 조건 저장할 때 그 모델로 실제 호출을 한 번 해 봅니다.
성공한 모델만 등록됩니다.
미지정 지정하지 않은 경로는 extractor 의 기본 모델로 동작합니다.
해제하면 그 상태로 돌아갑니다.
모델이 사라지면 등록 후 모델이 없어지면 자동으로 기본 모델로 대체돼 파싱은 계속됩니다.
이 경우 화면의 모델과 실제 도는 모델이 갈리므로 확인 버튼으로 점검합니다.
적용 범위 이 설정은 이 환경에만 적용됩니다.
dev 에서 바꿔도 prod 는 그대로입니다.
모델이 저장됐습니다. 실제 호출로 확인했고 바로 적용됩니다.
지금도 정상 응답하는 모델입니다.
지정을 해제했습니다. 이제 기본 모델로 동작합니다.

상품 페이지 HTML 에서 이름 · 가격 · 이미지를 뽑는 경로입니다. 텍스트와 JSON 스키마를 다룹니다.

업로드된 이미지에서 정보를 읽어내는 경로입니다. 이미지를 보는 능력이 필요합니다.
