동작 방식
어디에 실리나 User-Agent 헤더 끝에 값 전체가 실립니다. 브라우저 렌더에서는 Sec-CH-UA 헤더에도 / 앞 이름이 실립니다.
입력 규칙 이름 또는 이름/버전 형식입니다. 영문, 숫자, 점, 밑줄, 하이픈만 쓸 수 있고 40자 이내입니다.
공백, 괄호, URL 은 쓸 수 없고 bot, crawler, spider 가 든 이름도 쓸 수 없습니다.
빈 칸 비우고 저장하면 서버 기본 이름으로 돌아갑니다.
바꾸기 전에 이름에 따라 쇼핑몰이 요청을 막을 수 있습니다. dev 에서 먼저 바꾸고 실제 링크로 확인한 뒤 prod 에 적용합니다.
반영 시점 저장 즉시 이 서버에 적용되고, 다른 서버에는 최대 5분 안에 퍼집니다.
