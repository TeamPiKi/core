추출 라우팅 정책

배포 없이 플랫폼(도메인)별 추출 처리를 바꿉니다. 서브도메인은 자동 포함됩니다 (coupang.com 은 www·m 포함).
같은 도메인을 다시 추가하면 정책이 교체되고, 수정·삭제는 항목을 눌러 상세에서 합니다.
사유에는 날짜를 적지 말고 관찰한 내용만 남깁니다. 언제 바뀌었는지는 수정일이 자동으로 기록합니다.

정책 종류 설명 정책 없음 · SUPPORTED · HEADLESS_FIRST · UNSUPPORTED
정책추출을 어떻게 하나언제 이 정책을 쓰나
정책 없음 기본 추출
(정적 fetch → 구조화/LLM) 두 정책의 추출 방법은 완전히 같습니다.		 아직 확인하지 않은 도메인. 목록에 없는 모든 도메인이 여기 해당합니다.
SUPPORTED 기본 추출로 잘 된다고 실측으로 확인한 기록입니다. 추출 방법을 바꾸지 않고 사실만 남깁니다.
HEADLESS_FIRST 정적 fetch 를 건너뛰고
브라우저로 페이지를 열어 추출		 정적 fetch 가 늘 차단되는 곳. 실패할 것이 뻔한 시도를 기다리지 않습니다. 원격 추출(extractor) 경로에서만 유효하며, extractor 의 헤드리스 스위치가 꺼진 환경에서는 지정해도 효과가 없습니다.
UNSUPPORTED 추출하지 않음
(등록 요청을 400 으로 거절)		 봇 차단 등으로 어떤 방법으로도 상품 정보를 가져올 수 없는 곳.
알 수 없음 기본 추출
(모르는 정책이라 정책 없음처럼 처리)		 이 서버가 모르는 정책이 저장된 도메인입니다. 새 정책 종류를 추가한 버전에서 만든 뒤 서버를 그 이전 버전으로 되돌리면 생깁니다 (서버 코드는 되돌아가도 DB 의 행은 남습니다). 사용자 등록이 막히지는 않습니다. 항목을 눌러 아는 정책으로 바꾸거나 삭제하세요.
