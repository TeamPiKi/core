추출 라우팅 정책

배포 없이 플랫폼(도메인)별 추출 처리를 바꿉니다. 서브도메인은 자동 포함됩니다 (coupang.com 은 www·m 포함). 같은 도메인을 다시 추가하면 정책이 교체되고, 수정·삭제는 항목을 눌러 상세에서 합니다.
사유에는 날짜를 적지 말고 관찰한 내용만 남깁니다 — 언제 바뀌었는지는 수정일이 자동으로 기록합니다.

정책 없음 기본 추출 목록에 없는 모든 도메인. 아직 확인하지 않았다는 뜻입니다 — 정적 fetch 로 가져와 구조화/LLM 으로 읽습니다.
SUPPORTED 기본 추출 라우팅은 위와 똑같습니다. 다른 것은 하나 — 기본 추출로 잘 된다고 실측으로 확인했다는 기록입니다.
HEADLESS_FIRST 브라우저 직행 정적 fetch 가 늘 막히는 곳. 헛된 실패를 건너뜁니다. 원격 추출(extractor) 경로에서만 유효하며, extractor 의 헤드리스 스위치가 꺼진 환경에서는 지정해도 효과가 없습니다.
UNSUPPORTED 등록 거절 봇 차단 등으로 어떤 방법으로도 상품 정보를 가져올 수 없는 곳. 사용자의 등록 요청을 400 으로 거릅니다.
