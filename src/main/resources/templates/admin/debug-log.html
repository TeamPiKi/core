DEBUG 로그

조사할 때 서비스 로그를 DEBUG 로 켭니다. 평소에는 INFO 입니다.

동작 방식
대상 우리 서비스 코드(com.depromeet.piki)만입니다. Spring·Hibernate 같은 라이브러리 로그는 그대로 두어 로그량이 튀지 않게 합니다.
반영 시점 누르는 즉시 이 서버에 적용됩니다. 다른 서버에는 퍼지지 않습니다.
유지 메모리에만 있습니다. 재배포하면 자동으로 INFO 로 돌아갑니다. 조사가 끝나면 바로 끄세요. 켜 둔 만큼 Loki 무료 한도를 씁니다.
적용 범위 이 환경에만 적용됩니다. dev 에서 켜도 prod 는 그대로입니다.
반영했습니다. 이 서버에 즉시 적용됐습니다.

지금 상태

스위치 하나입니다. 켜면 DEBUG, 끄면 INFO 입니다.
