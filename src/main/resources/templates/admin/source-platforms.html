출처 몰 표시명

위시 응답에 나가는 출처 커머스몰 표시명(sourcePlatform)을 도메인별로 배포 없이 관리합니다.

동작 방식
임시 표시명 등록이 없는 도메인은 URL 에서 유도한 임시 표시명이 나갑니다.
예: shop.29cm.co.kr → 29cm
즉시 적용 저장·삭제는 즉시 적용됩니다.
과거 위시 항목에도 소급됩니다.
서브도메인 등록 도메인은 서브도메인을 자동 포함합니다.
등록이 겹치면 더 구체적인 도메인이 이깁니다.
교체·수정 같은 도메인을 다시 추가하면 표시명이 교체됩니다.
수정·삭제는 항목을 눌러 상세에서 합니다.
표시명이 저장됐습니다. (즉시 적용)
표시명이 삭제됐습니다. (즉시 적용 — 임시 표시명으로 돌아갑니다)
해당 도메인의 등록이 없습니다. (다른 운영자가 삭제했을 수 있습니다)
→
등록된 표시명이 없습니다. 모든 도메인이 임시 표시명으로 나가는 중입니다.
